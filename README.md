# CodexWithAnil — Bulk Word to PDF Suite (Daily Work Software & Website)

A high-performance, user-friendly software and website designed specifically for daily office document workflows.

---

## 🌟 Key Features

1. **50+ Bulk Word to PDF Conversion in 1-Click**
   - Drag & drop 50+ or 100+ Word files (`.docx` and `.doc`) at once.
   - Dual conversion engines:
     - **Native MS Word Engine**: Uses Microsoft Word directly for 100% exact layout, font, table, and image preservation.
     - **In-Browser Client-Side Engine**: Uses Mammoth.js & html2pdf for zero-install, 100% offline, private browser conversion.
   - Real-time progress bar with percentage, speed, and status per file.
   - **Download All as ZIP (Single Click)**: Package all converted PDFs into a single ZIP file without needing to download each file one-by-one.
   - Individual download button for each file.

2. **User-Friendly Eye-Care Color Combination**
   - **Light Theme (Day Comfort)**: Gentle soft slate (`#f8fafc`), crisp white cards, soothing indigo primary actions, and clear dark slate text for effortless reading during bright office hours.
   - **Dark Theme (Eye-Care Midnight)**: Deep midnight navy slate (`#0b1120`), glowing soft sky blue accents, zero glare for night shifts.
   - **1-Click Theme Switcher**: Toggle easily with persistent memory.

3. **Desktop 1-Click Shortcuts**
   - `Run_Word_To_PDF_Website.bat`: Double-click to launch the website and local high-speed converter instantly.
   - `Batch_Convert_Folder_Word_To_PDF.bat`: Standalone desktop script to convert an entire folder of 50+ Word files directly from the command line / desktop.

---

## 🚀 How to Run

### Option 1: Web Interface (Recommended)
1. Double-click `Run_Word_To_PDF_Website.bat` (or run `npm start`).
2. Your browser will open automatically at `http://localhost:3000`.
3. Drag & drop your Word files into the box.
4. Click **"⚡ Convert All Files to PDF"**.
5. Click **"📦 Download All as ZIP"** or download individual PDFs.

### Option 2: Folder Batch Converter (Desktop)
1. Double-click `Batch_Convert_Folder_Word_To_PDF.bat`.
2. Enter the folder path containing your Word files (or press Enter for default).
3. All files convert in seconds!
